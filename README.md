# claude-skill-audioanalysis

A reference skill for loudness standards, true peak, phase correlation and Dolby Atmos delivery. Platform targets change, always verify them against official specs.

## Install

Copy this folder into your skills directory, for example `~/.claude/skills/audioanalysis`.
